# Mackenzie Kramer — Portfolio

A warm, editorial-style personal portfolio built with plain HTML and CSS for GitHub Pages.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` and `YOUR-LINKEDIN` in `index.html`.
2. Add a professional portrait named `portrait.jpg` to `assets/images/`.
3. Add your résumé PDF as `assets/documents/resume.pdf` (or remove the résumé link).
4. Review every project description. Only publish work you have permission to share; use synthetic or de-identified examples for employer projects.
5. Personalize `about.html` and add publication links / project evidence to `projects.html`.

## Publish with GitHub Pages
1. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root (not the enclosing folder).
3. In repository **Settings → Pages**, set source to **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
4. Wait for the deployment and visit `https://YOUR-GITHUB-USERNAME.github.io`.

## Edit locally
Open `index.html` in a browser to preview. Edit HTML for content and `assets/css/style.css` for visual styling. Commit and push changes to publish updates.
